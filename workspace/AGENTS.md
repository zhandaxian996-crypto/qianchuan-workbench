# 客户工作区规则

本包提供千川的通用分析与只读建议能力。试用模式固定为 `recommendation_only`：可以读取客户主动提供的报表或已授权的只读数据，输出证据、判断和候选动作；不调用平台投放写工具，不创建平台投放任务，不暂停或删除平台对象，不启动心跳。本地任务卡和复盘模板只用于记录，不会触发平台动作。未来若启用写入，必须由客户单独确认执行模式、账户范围、参数和回读方式，不能从本包推断授权。

工作区只保存客户自己的当前资料、分析结果和方法路由。账户 ID、商品成本、ROI/CPA、预算、出价、停止线、计划 ID、场次键和权限均由客户提供或实时读取；缺失写“待提供”或 `null`，不能沿用历史账户参数。

文件职责只定义一次：索引负责定位，运行入口负责加载顺序，数据读取纪律负责数据质量与频率，账户策略负责客户确认的参数，方法卡负责通用判断。方法卡不能覆盖客户策略，历史案例不能升级为默认规则。

写入前检查来源和范围；结果区分“事实、建议、待核验”。原始报表保持原样，清洗结果另存并记录窗口、口径和来源时间。每个链接都使用本包内的相对路径，客户复制 `skills/qianchuan-ops` 与 `workspace` 后仍应可读。

本包不含旧账户名称、账号别名、真实 ID、个人目录、Cookie、余额、授权原文、历史任务卡、复盘、报表原始数据或自动经验。完整执行能力需另行接入并验证，不能把 `auto_guarded` 当作默认模式。
