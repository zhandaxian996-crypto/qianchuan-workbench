# O-5A 人群资产与 A3 种草素材决策纪律

本文件是工作区的按需参考模块。出现 5A 人群资产、A3 种草、品牌/商品 5A、种草素材与收割素材职责冲突时读取。普通盯盘不加载；官方定义另用 `qianchuan-ops` 核验。

它不替代当前巨量云图后台、官方定义、账户 Profile 或实时 MCP。平台版本、行业与品牌5A/商品5A的行为归类可能变化，具体字段与计算规则以当前后台和可核验官方资料为准。

## 1. 分层语义

- `O`：机会人群，尚未建立品牌关系；不属于5A关系资产。
- `A1`：了解人群，形成基础认知。
- `A2`：吸引人群，产生浅层兴趣或互动。
- `A3`：种草/深层互动人群，产生主动了解、问询、搜索或其他深层意向行为。
- `A4`：行动（Act）人群，业务上对应首购。
- `A5`：拥护（Advocate）人群，业务上对应复购。

点赞、评论、浏览深度、搜索、收藏、加购等行为落入哪一层，不凭行业记忆硬编码；先读取当前云图口径。公开资料可用于理解框架，不能覆盖实时产品定义。

## 2. 必须区分的数据对象

### 观看画像

回答“内容触达了谁”。它只能生成创作、主播表达和人群假设，不能冒充 A3 画像、购买画像或投放因果。

### 品牌5A

从品牌整体视角沉淀关系资产，包含多个商品与触点。5A总资产、总新增与总流失没有分层时，不能推断 A3 的量级、方向或素材贡献。

### 商品5A

下钻到具体 SPU。商品 A3 更接近商品主动行为，如商品点击、收藏、加购；商品 A4行动聚焦首购，A5拥护聚焦复购。评估单品种草素材时，优先读取该 SPU 的商品 A3，同时核对品牌 A3。

### 当前画像、购买阶段画像与拓展画像

- A3当前画像：描述已经形成的A3人群，是当前意向事实。
- A4+A5合并画像：只能描述购买阶段整体；未分列时不得分别声称首购画像或复购画像，也不得计算A3→A4转化率。
- A3拓展画像：描述潜在机会人群，是模型猜想与测试候选。
- 拓展画像不得冒充当前A3、购买人群或订单地域；必须通过受控投放和真实交易后验验证。

## 3. 种草与收割的职责分离

### 种草素材

主链：`O/A1/A2 → 内容深度消费与主动行为 → A3 → 后续A4行动（首购）`

主指标：

1. A3新增规模与占比；
2. O/A1/A2→A3加深率；
3. 去重增量A3成本；
4. 商品A3与品牌A3贡献；
5. A3→A4在客户约定后验窗口内的转化与同口径价值。

即时 GMV、订单和净 ROI 是现金风险与下游价值旁证，不是种草素材唯一主KPI。低即时ROI不能自动证明种草失败，高即时ROI也不能自动证明A3增长。

### 收割素材

主链：`曝光 → 点击/进房 → 停留 → 商品点击 → 支付 → 退款/结算`

主指标：有效点击与进房、停留与商品点击、支付率、订单成本、声明口径的净GMV与净ROI。A3新增可作为辅助，不替代成交责任。

### 种收双优

只有同一素材同时取得有效A3增量和健康A3→A4/成交后验，才标记为种收双优。不得用模型标签、素材名称或一两单直接授予该角色。

## 4. A3 评估的四层结构

1. **规模**：A3存量、A3新增、A3占比、商品A3新增。
2. **效率**：O/A1/A2→A3加深率、每千次有效曝光新增A3、单个去重增量A3成本。
3. **质量**：主动行为构成、A3来源、A3画像与A4画像的相似与差异。
4. **价值与健康**：A3→A4后验、A3维持、关系加深、关系疏远与真实流失。

A3存量下降不等于失败。A3流向A4属于良性转化，必须与降级/流失分开；只有总资产新增/流失字段时，不做A3判断。

## 5. 四象限

| A3表现 | A4行动（首购）/成交表现 | 角色与动作 |
|---|---|---|
| 高 | 高 | 种收双优；验证规模化后放大 |
| 高 | 低 | 纯种草；保留并补后链路收割 |
| 低 | 高 | 收割；按成交素材管理 |
| 低 | 低 | 达到样本后进入低效候选 |
| 总5A高、A3低 | 未知 | 浅层曝光；主要贡献A1/A2，不称种草赢家 |

所有“高/低”阈值来自同账户、同商品、同触点、同窗口的可比基线或受控实验，不迁移固定行业倍数。

## 6. 禁止误判

- 禁止用5A总资产、总新增或观看画像冒充A3。
- 禁止用当日新增全部归因给某条种草素材；需素材/触点归因或增量对照。
- 禁止用短时高ROI、一两单、点赞评论或模型分单独证明A3价值。
- 禁止用即时低ROI或0单单独淘汰种草素材。
- 禁止把A3→A4造成的A3库存减少写成流失。
- 禁止把品牌A3直接等同于某个SPU的商品A3。
- 当前投放目标若为净成交ROI，只能称为“使用种草型内容的成交优化任务”，不能称为A3优化任务。

## 7. 数据最小集

评价A3至少需要：

1. A1～A5逐层量级与占比；
2. O/A1/A2→A3流入与加深率；
3. A3→A4行动（首购）流转；
4. A3来源与行为构成；
5. 目标SPU的商品A3；
6. 素材/触点消耗与A3归因或可比增量对照；
7. 当前统计窗口、去重规则与归因窗口。

缺少前五项时只输出数据缺口与实验方案，不宣称种草有效或无效。

## 8. 与千川盯盘的协同

- 盘中仍需监控平台1小时净ROI、净GMV、订单和流速，控制现金与承接风险。
- 种草素材使用独立角色标签和后验台账，不能与收割素材共用单一ROI榜。
- 素材止损仍需有效样本与多证据；A3数据不可用时，可设计未来单变量开启/暂停/恢复的对照方案，当前只读试用包不执行这些操作；该类实验即使另行实施，也只是观察组合增量，但只能证明组合贡献，不能命名为A3增长。
- 本包对品牌广告、云图、Feed/人群定向只做数据分析和建议，不发起写操作；方法卡不启用账户权限。
