# 成本保障判定

用途：回答有没有保障、是否满足条件、改动会不会影响资格、赔多少、预算是否可能覆盖门槛。整理于2026-09-08。主要依据为[QC-OFFICIAL-015 全域保障规则摘录](../证据摘录/全域保障核验摘录.md)与[QC-OFFICIAL-016 追投手册摘录](../证据摘录/追投功能核验摘录.md)，均为已取得官方内容的本地收录，非官方全文。更新日期、摘录范围见文件首部。

## G1 先分产品，再判条件

| 产品与目标 | 本卡能回答的范围 |
|---|---|
| 直播全域主计划，控成本，投放成本优化，支付/净成交ROI | 按G2判定；净成交使用对应净口径 |
| 控成本素材追投，成交出价 | 按G3判定 |
| 控成本素材追投，ROI目标 | 按G3判定；确认实际任务的支付/净成交目标 |
| 放量素材追投 | 不支持成本保障，不能用主计划保障兜底 |
| 一键起量 | 本次核验规则明确其消耗不参与保障、订单不计门槛 |
| 主计划放量投放 | 存在独立保障机制，不能因“放量追投不赔”判为不赔；按G6查专属条件 |
| 乘方、综合成本优化、随心推、搜索工具 | 不套G2/G3；需该产品独立条款与实际模式。包内摘录未覆盖完整资格时仅报告覆盖缺口 |

“直播间已有10单”“开着保障标签”“已经超成本”单独都不能证明会赔。还须核对保障期间的模式历史：同一计划用过乘方、或调控工具用过综合ROI，按QC-OFFICIAL-015第1节转入乘方整体核算，不能只看当前模式。标注“定向测试”的产品不按普通自动发放承诺。

## G2 主计划：按一个自然日单独核算

适用前提见G1，不适用于综合成本优化/乘方。依据QC-OFFICIAL-015第2节。

同时检查：
- 该自然日符合规则的转化订单数≥10。净成交口径剔除支付成功1小时内主动退款订单，还需按官方异常交易规则剔单。
- 实际ROI < 全天目标ROI × 80%，是严格小于；恰好等于80%不触发。
- 直播场景相邻两次修改ROI数值间隔≥15分钟，全天数值修改≤24次；不同ROI优化目标之间切换，间隔≥1小时。不论计划启停状态均计算。
- 主计划数据与追投工具数据独立，不用直播间混合总数替代保障单元的数据。

产品允许修改不代表修改后仍享保障。更保守的账户冷却可继续遵守；上述数字不能反向授权更频繁调参。

## G3 控成本追投：按单任务的首日＋次日核算

依据QC-OFFICIAL-015第3节、QC-OFFICIAL-016第4～5节。

- 起点是任务首次产生投放数据之日，不是仅创建/过审之日；截止次日结束。例如周一23:50开始，覆盖周一与周二，不是连续48小时。
- 该任务保障期内符合口径的转化数≥10。多素材同一任务按任务合计；不同任务的5单＋5单不能拼成10单。
- 成交出价：实际成交成本 > 目标成本出价 × 120%，严格大于。
- ROI目标：实际ROI < 目标ROI × 80%，严格小于。
- 每个自然日，修改该追投出价/ROI目标次数≤2；修改该追投定向＋主计划定向合计次数≤2。追投手册说明主计划此处指限运定向；不得把修改主计划预算/ROI误记成追投出价修改次数。
- 当天已经改过2次，第三次即可能失去保障条件；“间隔30分钟”不能替代每日次数条件。改预算与改出价要分开记录，但不能因此声称任意幅度/频次的改预算都绝对不影响保障，仍有一般合理投放条款。

保障期不是每日重置；同一个长期任务第三天不能继续套首两日保障。删除新建不继承旧任务的订单，也不构成通过反复重建套取保障的依据。

## G4 通过资格检查后才计算金额

可选离线复算工具与输入格式见[计算说明](../计算说明.md)。工具不会替代以下资格核对。

令C为保障单元内实际消耗，G为对应GMV，N为符合口径的转化数。先确认分母有效、订单归属、退款剔除与目标变更记录；字段不足时可以做“按给定数字的条件计算”，不能称已获平台确认。

| 类型 | 总出价金额T | 有变化时的合成目标 |
|---|---|---|
| ROI（G2或G3适用的投放成本口径） | T = Σ(各时段G_i ÷ 该时段目标R_i) | R = 总G ÷ T |
| 成交出价追投 | T = Σ(各时段出价B_i × 对应转化N_i) | B = T ÷ 总N |

满足全部条件时，金额 = C − T。不能按最后一次目标算全周期，也不能把多个ROI目标做简单平均。恒定目标时可简化为 C−G/R 或 C−B×N。80%/120%用于判断是否触发，不能把它再次乘进上述赔付公式。

条件示例（非账户参数）：
- 固定出价20，10单，花240：CPA=24，恰好120%，不触发；花260则CPA=26，若其他条件满足，金额260−200=60。
- 前段出价20得5单，后段出价30得5单，总消耗320：T=250，合成出价25，CPA32>30，条件金额70。不能按最后出价30算出20。
- 固定ROI目标2.6、G=1300、C=700：实际约1.86<2.08；其他条件满足时，金额200。
- 主计划和追投分别算。即使合起来看似达标，也不合并核算门槛或赔付。

## G5 将规则用于预算与动作判断

以下是依据规则的操作推导，不是平台要求或跨账户策略：

- 固定出价B、整段实际消耗上限M，要同时满足至少10单及CPA>B×1.2，必须有实际消耗>12B。例：B=20而整段最多花100，无法同时够10单又触发超成本；100元可以试投，但不能承诺保障。预算上限不等于实际消耗，更不应为了跨过门槛主动追加。
- 查看数据不等于调整参数；观察频率取账户读取纪律，出价次数按G3记账。
- 保留潜力任务可继续积累单任务样本；是否续投仍由账户止损/经营条件决定。保障条件不能覆盖已明确的保护性停止线，也不能授权追加预算。
- 暂停能释放未消耗调控额度；已满足保障条件的任务删除不影响赔付。未达标任务提前结束可能因单量不足而不具资格，不能无证据地声称“删除必然阻断数据回传”。详见[素材追投](素材追投判定.md)。
- 输出可用“已满足/未满足/待核验”逐项说明，最终发放仍以平台核算为准。已知一项不满足即可说明当前为何不具资格，不强制拉齐全部无关数据。

保障以不可提现的赠款发放，不是现金退款。规则注明一般回传期；产品手册给出T+2测算、T+3开始到账的例子，两者不是同一阶段，不能承诺次日到账。

## G6 主计划放量与未覆盖产品

[QC-OFFICIAL-004 放量手册](../证据摘录/主计划放量要点.md)“四、相关规则”包含独立的账户资格、统计周期、建议预算、有效投放日和预估ROI条件；回答该产品时读取包内对应摘录及清单版本备注，不套素材追投的10单/首两日规则。

已发现同文件前部旧对比表写5天、后部2026-05-18规则表写≥3天；主计划调价间隔也有旧表与后续规则的差异。必须按明确章节、适用产品、规则版本解释差异，不能混成一套。没有预估ROI时不能只凭采纳预算承诺赔付。乘方独立保障尚缺可靠完整本地条款；不得把QC-OFFICIAL-014摘要中的笼统声明升格为完整资格规则。
