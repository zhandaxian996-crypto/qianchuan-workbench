# 素材追投判定

用途：区分放量与控成本追投、核对创建限制、预算占用、暂停/删除，以及不起量的解释边界。整理于2026-09-08。平台条件用于核对产品；具体素材、预算和止损取使用者当前账户策略。

## 先确认是在操作哪个对象

| 用户描述或界面 | 应归类 | 后续读取 |
|---|---|---|
| 指定一个或多个视频，选择放量追投，设置金额/时长 | 放量素材追投 | 本卡；若问保障，读成本保障卡 |
| 指定素材并设置成交出价、或ROI目标 | 控成本素材追投 | 本卡＋相关成本保障条款 |
| 整个直播全域计划选择放量投放 | 主计划放量投放 | QC-OFFICIAL-004相应章节；不能套素材放量追投 |
| 仅说“放量”“100元3小时”，没有界面/模式证据 | 模式尚不能仅凭金额和时长确认 | 先从已有任务说明/元数据辨别；仍不清楚时只问对象或模式 |

[QC-OFFICIAL-016 追投手册核验摘录](../证据摘录/追投功能核验摘录.md)第1节明确：放量追投不支持成本保障，控成本追投支持独立保障；两种追投方式可以搭配。不要把主计划转投的互斥关系套到两类追投上。

## 创建与额度检查

依据：[QC-OFFICIAL-009 Q&A快照](../证据摘录/追投问答节选.md)（2026-07-22，partial）；QC-OFFICIAL-016第2～3节（2026-09-08核验摘录）。

1. 检查素材当前是否可投、审核与排除状态，实际能力按当前界面/Schema/回读确认，不从历史快照推断一个素材当前可投。
2. 已收录规则：控成本/放量、视频/直播间画面追投共用40个任务上限；每日最多新建500条。具体当前计数/状态以服务端为准。
3. 成交出价任务的创建预算下限为5个成交成本。例：出价20，预算至少100；出价20.5则至少102.5。这是平台创建门槛，不是建议必须花掉的金额，更不是保障资格门槛。
4. 控成本追投还受直播间维度调控额度约束。判断可用额度要同时看已消耗和在投任务占用，不能只看剩余现金。
5. 当前已核验说明：暂停任务未消耗的预算不再占用每日调控额度；已消耗部分仍计入。放量追投没有这项控成本调控额度限制，不代表无实际预算上限或可以超授权消费。

## 暂停、删除和重新筛选

- “需要释放未消耗额度”不必直接推导成删除，暂停已能实现该目的。
- 任务删除与视频库素材删除是不同对象。处理追投不能顺带删除原始视频。
- 已满足成本保障条件的追投任务，删除不影响获得保障；未满足条件时不能借此断言“先删除也能赔”。首次投放时间、单任务累计转化及调整次数见[成本保障判定](成本保障判定.md)。
- 每天重新评估素材是账户方法选择，不等于平台要求每天删除所有追投。是否保留旧任务按账户策略与本次目标判断；需要保障时先说明重建使任务样本分开的影响。
- 不把平台支持长期投放解释成每天自动续开。手动暂停与预算不足/下播造成的系统暂停，其恢复行为不同；需要续开时查当前状态及原文对应条款。

## 不起量：先核对证据，再解释

| 看到的现象 | 原文支持的检查方向 | 不能直接推出 |
|---|---|---|
| 单条素材与主计划相同，追投跑量弱 | 官方Q&A提示：出价没有优势时较难跑量；同时查预算、目标和当前状态 | “主计划拿走了所有高意向用户”或某个内部竞拍层已经拦截 |
| 控成本任务预算很小 | Q&A把约10个转化成本作为探索建议 | 要求所有账户立即加到10倍、必须花满，或已经满足10单保障 |
| 支付目标切换净成交后跑量下降 | 核对是否按对应结算率折算目标 | 仅凭切换发生就认定产品失效 |
| 初期消耗少、暂未达ROI | 历史Q&A提示可能处于样本积累阶段 | 以“算法探索”为由越过账户明确止损线 |

同素材组合投放是产品建议，不是固定包数量；任务出价不能由ROI与客单价的换算机械决定。计算边界见[指标口径](指标口径与换算.md)。
