# 目标调整与效果判断

用途：回答有效投放、目标折算/拿量建议、扩量后ROI下降、素材GMV与ROI冲突。整理于2026-09-08。将官方建议与账户决策分开，不从官方案例自动生成预算或止损阈值。

## P1 三种判断分开

| 用户想判断什么 | 看什么 | 不能替代什么 |
|---|---|---|
| 是否完成有效投放 | 目标采纳、消耗、投放时长三个条件及当日页面 | 不等于成本保障资格或账户盈利 |
| 是否享成本保障 | 产品对应周期、订单、效果偏差、操作历史 | 不能只用有效投放状态判断 |
| 是否值得继续/扩大 | 当前账户经营目标、可靠样本、增量表现与风险 | 官方产品目标不能替代商品利润与账户止损 |

## P2 有效投放的本地规则

依据：[QC-OFFICIAL-013用户原文快照](../证据摘录/有效投放用户摘录.md)（2026-08-29，excerpt，未在线复核版本），辅以[QC-OFFICIAL-011](../证据摘录/有效投放早期要点.md)（2026-07-22，unknown）。

三项条件：目标不超过系统建议；每日直播全域消耗至少200元；投放时长不少于直播时长50%。这些是快照中的产品判定，不是让账户为达标必须烧够200元。

容易漏掉的口径：
- “暂无推荐”时，013说明任意设置的ROI目标均判为采纳；不等于任意目标都能拿量或盈利。
- 全天净成交ROI目标 = 纳入范围的净成交GMV ÷ Σ(各时段净成交GMV/对应目标)。目标计算不含一键起量、视频追投和乘方期间数据。
- 消耗及投放时长按计划维度统计，013说明全域/乘方下净成交ROI投放均纳入。不要把目标计算的排除范围照搬给另外两项。
- 资料提到未升级老计划可能仍展示支付ROI判定，不能按全量升级措辞猜当前账户页面。

## P3 调整目标前，分清概念与证据

依据：[QC-OFFICIAL-002净成交手册](../证据摘录/净成交出价要点.md)、[QC-OFFICIAL-003拿量建议节选](../证据摘录/拿量建议要点.md)、[QC-OFFICIAL-007操作节选](../证据摘录/投放操作建议节选.md)。前者有2026-08-24比对记录，后两者为2026-07-22的partial/excerpt。

1. 切换支付/净成交先做口径折算，见[指标口径](指标口径与换算.md)；目标数字下降不直接等于放宽经营要求。
2. 同一优化口径下，下调ROI目标通常提高拿量竞争力；提升幅度取决于实际环境。系统拿量建议是预估，缺少建议不等于一定不能增量，显示建议也不保证实现。
3. 区分预算与出价：预算是容量/消费约束，出价/目标影响成本与竞争力。消耗远未触及预算时，增加预算不能据此保证起量。主计划放量如何用预算探索成本，另读QC-OFFICIAL-004对应产品章节。
4. “单次约10%”“观察1～2小时”“稳定投放3天看结算”等是资料中的产品使用建议。不能变成所有账户统一的自动动作，也不能以观察期为由延迟明确止损。
5. 保障所需调价间隔/次数按[成本保障](成本保障判定.md)的产品分支核对，不从旧建议段拼出新的硬限制。

## P4 素材数据：先看组合，再定位责任

依据：[QC-OFFICIAL-006素材看数攻略](../证据摘录/素材看数要点.md)（2026-07-22，unknown）及[QC-OFFICIAL-012 GMV最大化节选](../证据摘录/GMV组合逻辑节选.md)（2026-07-22，partial）。

- 官方产品目标是在整体ROI约束下争取更大GMV；不同素材可能承担拿量与维持效率的不同作用。
- 单素材低ROI、高消耗，并不能单独证明它无贡献；投中处理头部GMV素材前，核对其贡献、组合效果及账户风险。
- 同样，不能由产品介绍中的“系统最优解”宣称实际投放永远最优，或低效素材永远不能停。案例解释只能支持可能性，具体动作取当前证据与账户策略。
- 整体维度可能混有自然与付费等结果，不能把素材整体订单全部当付费增量；需要追投效果时单独看该追投单元。
- 同时比较新增消耗、新增成交和累计表现，区分预算扩大后效率变化与素材永久失效。这是分析推导，不能借此声称已证明因果。

## P5 资料中的历史说法不要升级为现行能力

[QC-OFFICIAL-008效果排查节选](../证据摘录/历史效果排查节选.md)来自早期使用宝典，包含“不支持手动定向”“常规报表不包含全域”等泛化描述及内测效果数字。它们不能覆盖当前产品/数据接口；例如追投支持的定向在[QC-OFFICIAL-016](../证据摘录/追投功能核验摘录.md)有具体更新。历史300元/50转化和3天测试等也不能作为账户硬性启动或止损门槛。

对比效果时可借鉴货盘、开播时段、投放时长可比的思路；用快照回答时说明日期，不把内测中位数或预计增长写成当前账户保证。
