## 1. 第二、五～六条：适用、订单、独立统计和回传

> 转化订单数：指成本保障期间客户投放带来的，剔除异常交易数据（含直播间1分钟退款、购物车凑单1分钟退款及平台判定的异常订单数等，以下或称“剔除订单”）后，平台实际统计的商品成交订单数。

> 素材追投、搜索抢首屏、看后搜一键投等调控工具与原全域主计划相互独立，单独设置预算和目标，单独统计消耗、转化订单数、成交金额及成本保障金额等。

本次读到的同节内容还明确：一键起量预算不支持保障，一键起量带来的订单不计入保障订单门槛；保障GMV使用对应优化目标与符合口径订单的金额，实际消耗包含现金、赠款等相应消耗。上述为条款转述，不是新增通用数据字段定义。

> 其中，推直播的数据回传周期一般是保障结束后1个自然日，推商品的数据回传周期一般是保障结束后7个自然日，下表另有说明的除外。

此处是数据回传时间，不能等同于赠款确定到账时间。第六条及后续条款另说明审核与发放可能延迟。

第二条说明：同一计划在全域期间切换使用过乘方，或调控工具的ROI优化目标使用过综合ROI，该计划/调控工具将整体按照《乘方成本保障规则》统计。因此只确认当前模式不够，还须核对期间模式变更。第六条另说明，标为“定向测试”的投放产品不支持自动发放，可能按测试情况调整和不定期核算，不能仅按保障标识判断。

## 2. 第二章表一：控成本投放—整体支付ROI、净成交ROI

表格适用范围：投放成本优化；综合成本优化在别表，本摘录不覆盖。

- 成本保障期间：每单个自然日。
- 转化订单数：每个自然日内转化订单数≥10；净成交ROI投放期间的订单，剔除支付成功1小时内主动退款订单。
- 效果条件原式：实际ROI < 全天目标ROI*80%。
- 全天目标ROI = 总GMV/总出价金额。
- 直播场景修改条件：不论计划启停状态，相邻两次修改目标ROI数值的操作时间间隔≥15分钟，且全天目标ROI数值修改总次数≤24次；不同ROI优化目标切换间隔≥1小时。
- 推商品场景相邻两次修改ROI目标数值或切换ROI优化目标，间隔均≥1小时；不得把它套给直播数值修改。
- 成本保障金额 = 总实际消耗 − 总出价金额。
- 总出价金额 =（A时间段GMV/A时间段目标ROI）+（B时间段GMV/B时间段目标ROI）+……。

上述列表是原表格按字段重排，数学符号统一；订单仍须遵守通则的异常数据剔除要求。

## 3. 第二章表五：素材追投

| 项目 | ROI目标 | 成交目标 |
|---|---|---|
| 期间 | 首次投放素材追投任务之日起至之后1个自然日内 | 首次投放素材追投任务之日起至之后1个自然日内 |
| 订单 | 总转化订单数≥10 | 总转化订单数≥10 |
| 效果条件 | 实际ROI < 目标ROI*80% | 实际成交成本 > 目标成本出价*120% |
| 出价修改 | 单日修改追投ROI目标次数≤2 | 单日修改追投出价次数≤2 |
| 定向修改 | 单日修改追投定向及主计划定向合计次数≤2 | 单日修改追投定向及主计划定向合计次数≤2 |
| 合成目标 | 目标ROI=总GMV/总出价金额 | 目标成本出价=总出价金额/总转化订单数 |
| 总出价金额 | Σ各时间段GMV/对应时间段目标ROI | Σ各时间段目标成本出价×对应转化订单数 |
| 保障金额 | 总实际消耗−总出价金额 | 总实际消耗−总出价金额 |

表格按原条件重排；全部条件须同时满足，不把其中一项当充分条件。主计划与追投各用自己的数据。

## 4. 第九条、第三章及常见问题

> 其使用期限为自发放之日起1年……不可提现、不可转让至其他账户、不可开票。

> 如投放初期出现成本波动时客户立即暂停计划/订单，将导致客户无法根据本规则获得成本保障。

第二句需连同具体资格条件理解，不可改写成“任何正常暂停都必然丧失保障”，也不能据此延迟账户保护性止损；有关已满足条件后删除追投的具体解释，见QC-OFFICIAL-016。

第十四条还列有不合理幅度/频次的启停、定向、ROI、出价、预算调整及异常交易等情形；不能只因未超某项次数便承诺完全免责。本摘录未收录所有违规和处置条款。

常见问题：
- 赠款会用于后续投放，不可退款或提现。
- 可在巨量千川PC后台“资金管理—财务流水—收支明细”查看，资金详情为补偿赠款。
- 系统审核、数据异常等情况可能延迟发放；金额小于0.01元不发放。
