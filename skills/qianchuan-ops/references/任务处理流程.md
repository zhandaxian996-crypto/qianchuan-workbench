# 任务处理流程

这是跨账户的工作方法，不包含固定预算、出价、素材数或盈利线。规则数值见相应规则卡，当前账户值由使用者提供。

## A. 规则问答或条件计算

1. 从用户描述辨认产品、目标和问题。只说“放量”但会影响结论时，区分主计划放量与指定素材放量。
2. 读相应规则卡及包内证据；标出已收录版本。
3. 对给定数字复算。可用[计算器说明](计算说明.md)处理分段目标和严格边界；计算成立不等于真实账户资格确认。
4. 给结论、关键条件及与用户操作的关系。完成问题即可，不要求接入账户或加载无关资料。

## B. 离线报表分析

1. 先查表结构、日期覆盖与汇总层级。保留原文件；不要将全周期汇总与逐日行相加，不把重叠报表重复统计，不把缺日期当0。
2. 明确任务/素材ID、日期或时间段，以及消耗、订单、GMV/ROI的支付或净口径。报表没有当前状态、出价或变更历史时直接标缺，不从导出文件名推断。
3. 同对象同窗口比较结果；需要总体ROI时用同口径总GMV÷总消耗，不简单平均各行ROI。样本不足的相对第一名不自动变赢家。
4. 判断素材时结合贡献和组合结果，见[目标调整与效果判断](规则卡/目标调整与效果判断.md)；追投效果以追投自身数据判断。
5. 应用用户提供的目标和停止条件；没有账户阈值可先描述表现与候选。若用户要具体停投或放量决定，按[资料准备流程](工作区与资料准备.md)核对已有依据并主动索取关键缺项，不只列“资料不足”，也不编造经营线。
6. 交付一张必要的比较表及下一步：对象、数据窗口、证据、当前判断、建议动作/待补数据。建议与实际操作分开。

没有表格读取库时，先使用宿主现有文件/表格工具；若文件确实无法解析，说明格式缺口并接受可读导出，不默默把未知文件当空数据。不因本技能未带Excel库而停止可完成的规则解释。

## C. 追投筛选与预算取舍

1. 从近期可比结果建立候选；当前主力由本场可靠结果决定，历史只给候选资格。
2. 区分探索与已验证放大。探索允许尚无盈利结论，但实际试错必须服从用户的预算和停止边界。
3. 对一个任务既看任务结果，也看包内素材，避免高消耗单条掩盖其余素材的样本缺口。
4. 预算紧张时比较当前各任务继续投入的依据；暂停能释放未消耗控成本额度，是否删除/重建另核对任务身份与保障周期。
5. 续预算后检查新消耗带来的新订单/GMV，不让早期累计好结果掩盖后续恶化。观察窗口和追加幅度采用当前账户约定。
6. 无明确合格候选时，不为凑素材数量或保障订单数强行增加消费。

需要执行时交给[接入与执行](接入与执行.md)的闭环；材料不足时仍交付可审阅的候选和缺口。

## D. 主计划目标调整

1. 先判断是主计划问题还是追投问题。没有可用拆分证据时，不把总流速变化直接归因给主计划。
2. 核对目标口径是否改变、是否完成必要折算，预算是否实际成为限制，以及当前数据是否可比。
3. 将系统建议视为估计，结合当前目标、经营约束和实际结果说明上调/下调的理由与代价。
4. 核对该产品调价间隔、次数及本账户更保守的限制；是否保保障与是否止损分别判断。
5. 按本次授权执行一项清楚可归因的调整并回读；后续按约定窗口比较新增结果，不把“改了以后变好”直接称为因果证明。

## E. 复盘与经验提炼

先交代使用了哪些数据、覆盖哪个对象/日期；把观察、推断、动作和后验结果分开。缺少对照或可比条件时不宣称某操作必然有效。

结果按[工作区与资料准备](工作区与资料准备.md)定位，复用其分析复盘模板，维护同主题现行结论；账户事实、策略、当场状态和历史证据分别更新。任务结束时盘点可再生成的过程文件，先核查用途与引用，按使用者已明确的清理范围处理。只有跨场验证、适用条件和失效边界清楚的通用方法才考虑更新技能。一次实验的预算、阈值和结果不能成为所有使用者的默认策略。
