# 离线成本保障计算

工具：[scripts/cost_guarantee_calc.py](../scripts/cost_guarantee_calc.py)。Python 3.9及以上，仅标准库，无需安装第三方库，不联网、不读账户、不写投放。

先按[成本保障判定](规则卡/成本保障判定.md)确认产品范围。工具只支持普通投放成本口径的main_roi、boost_roi、boost_cpa；乘方、综合目标、放量主计划、放量追投等不能硬套。

## 如何调用

在技能根目录运行以下命令，或将脚本与输入路径写成接收方的绝对路径：

```text
python scripts/cost_guarantee_calc.py --input assets/cost-example.json
```

默认结果输出到终端。需要文件时增加 `--output 接收方输出目录/计算结果.json`；不覆盖输入或既有结果。没有Python时，按规则卡公式计算即可，其他规则问答和分析功能仍可使用。

## 输入字段

- kind：main_roi、boost_roi、boost_cpa之一。
- spend：整个保障单元的同口径消耗，非负数。
- periods：按目标不变的时间段给出数据。每段target为正数；成交出价模式每段orders为非负整数；ROI模式每段gmv为非负数，可给orders。
- 货币/目标推荐以十进制字符串给出，如"20.5"。不接收NaN、负数或无效目标。
- orders必须是该保障单元符合口径的订单数；退款剔除、任务归属和周期由使用者核对，工具不从汇总表自动推断。

[示例输入](../assets/cost-example.json)是虚构的分段出价计算题，不是默认投放配置。示例条件计算结果为70，不代表实际获赔。

## 怎样解读结果

- numeric_status仅说明输入数字是否达到已收录订单/效果门槛。
- total_target_amount为按各时段累加的总出价金额；不能改用最后一次出价或ROI。
- formula_difference为消耗减总出价金额的纯数学差额，不等于可领赠款。
- conditional_amount_if_all_rules_satisfied仅在数字条件满足时给出条件金额；其他资格仍待核验。数字条件不满足返回0；信息不足返回null。
- eligibility_confirmed始终为false：工具从不确认真实资格、到账或盈利。
- not_checked列出仍需外部证据的范围。ROI缺订单数时仍能算公式，但不能判10单门槛；零订单/零GMV不强行产生有效加权目标。
