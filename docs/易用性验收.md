## 新手仍会遇到的门槛

1. 新电脑需要 Node.js/npm，并需要联网安装项目依赖。Agent 按随包安装说明自行安装；Windows 启动入口缺少 Node 时可调用系统包管理器。安装包尚未内置运行环境，无 Node 的完整安装分支未在本机重新实装（本机已有合适版本）。
2. 用户仍须本人登录千川，通过 Cookie Editor 导出文件后在本机导入。当前没有一键登录，后续易用性优化应优先解决这一步。
3. Agent 客户端必须有本地执行或 MCP 能力。项目提供通用工具和说明，但尚未逐一实测豆包、WorkBuddy、DeepSeek 等客户端，不能保证自动识别同一种配置格式。
4. 直播中的盘面读取、长时间连续盯盘、客户端通知和真实定时安排还需开播后验证。本轮没有启动持续循环或实际定时任务。

## 盯盘如何接入

已连接 MCP 的 Agent 每次调用 monitor_once；有本地命令能力的 Agent 可使用 tools/monitor.cjs。程序负责取数和标记变化，Agent 负责解释结果、按用户授权安排频率并处理提醒。外部定时安排收到 paused:true 后，由 Agent 暂停该安排；本工具不能控制所有客户端的调度器。

本机循环连续取数失败 3 次会停止；服务不可用或身份不符会立即停止并返回暂停提示。并发占用跳过本轮。未变化时 should_notify 为 false，但仍必须检查数据有效性和错误。默认只读，不修改广告。
